# kaolin-assets

Binary assets for the Kaolin Paper desktop, fetched by a NixOS flake.

- `gtk/kaolin-lavender/`: GTK theme, output of a one-off [Themix](https://github.com/themix-project/oomox) run.
- `kvantum/KaolinTemple/KaolinTemple.svg`: Kvantum SVG, recoloured from KvAdapta. The `.kvconfig` comes from the flake.
- `wallpapers/`: `kaolin-paper-shanshui-clean.png` is the default, the rest are alternates.
- `fastfetch/cat.png`: fastfetch logo.
